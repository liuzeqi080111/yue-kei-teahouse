# 11 月 21 日玩家验收修复

依据本轮用户试玩反馈。基线来自 4226 固定试玩副本。修复范围包括人物手部与持物、周叔收报与坐姿、拼桌对话视线、旧相叙事一致性、街坊活动、阿晴持衣、平稳跟随和借衣过早归还。

验收要求

- 正常入口、试镜和故事中的人物动作一致。检查真实蒙皮和道具接触，保存实际游戏截图及近景。
- 玩家向周叔问拼桌时看向周叔。旧相台词、字幕和录音解释同一件事。
- 跟随中拖动视角后保持玩家的观看方向，移动、地面高度变化和到达不造成快速摆头。
- 街区多人有可见的生活动作及行走，交谈对象保持可交互。阿晴随剧情持有可见衣物。
- 借衣后须完成面试及取回借衣才能归还。旧版本过早归还存档可继续借衣，正常完成归还后不能重复借出同一任务物品。
- 开发自检与用户验收分别记录，逐项注明覆盖和剩余问题。
