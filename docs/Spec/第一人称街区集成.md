# 第一人称街区集成

基线 `5085687` 已包含 OW1 `d939a0f`，集成分支为 `codex/neighborhood-first-person`。视觉以 2026-11-18 的 `neighborhood-walk` 为准。

| 剧情动作 | 地点和人物 | 已有规则入口 | 游戏内可见结果 |
| --- | --- | --- | --- |
| 出门、听缘由、答应或推迟 | 安和楼梯口，`friend`、`aqing → qing` | FP1 `createFp1Story` 的开场节奏，交接时执行 OW1 `coat-start` | 阿晴交出取件单与错衣，答应后朋友带路 |
| 进门、交谈、亲手递单、选路 | 洗衣店侧门和柜台，`fang` | `fp1-travel` / `fp1-follow` 移动，OW1 `shop-check` 核对；FP1 的三个路线选择接入同一 OW1 状态 | 三次操作彼此独立，核对后更新下一站 |
| 问阿明、核对衣服再归还 | 粤记门口 `aming → ming`、门旁熟客 `regular → guest`、住处阿晴 | OW1 `guest-found`、`coat-detail`、`coat-swap`、`coat-return` | 交换后背包有原衣，交还后阿晴出发 |
| 借或买、面试后归还 | 衣摊 `ling`、住处阿晴 | OW1 `coat-loan`、`coat-buy`、`coat-emergency`、借衣归还系列；买衣付款人按最新产品事实修正 | 阿晴支付新衣，玲姐收回借衣，原衣误会保持可追查 |
| 追问来历、转达或购买 | 树下 `lin → lam`、唱片摊 `ale → lok`、`buyer` | OW1 `record-*`、`buyer-consent`、`consent-relay` | 林伯按收到的线索或唱片回应 |
| 观察、听双方、协商和复访 | 粤记门口阿明、由衣摊经营者玲姐负责的门口陈列 | OW1 `stall-*`、`rackStatus`、`restEvent` | 通行空间与陈列随约定和时段变化 |
| 進茶餐厅、返回门口 | 粤记 | `app.js` 的世界餐厅进出与持久化 | 室内保留餐局，回到同一门口 |

OW1 的 world 提供所有剧情标记、物件、交易、金钱和时段。FP1 的独立示例会在选路后停止，没有既有交接事件。本入口沿用开场节奏和跟随控制器，路线选择由 OW1 规则保存。语音走 `createNeighborhoodVoice`，使用 `npcContext` 与实际可执行动作。
