# 粵記茶餐廳 · 一席廣東話

第一人称像素风粤语茶餐厅游戏。推门、入座、点餐、改规格、上菜、加水、核对账单，再完成虚拟付款。

## 在线试玩版

GitHub Pages 发布版本支持完整按钮流程、粤语字幕、普通话释义、粤拼、背景器乐和手机布局。
**语音识别、AI 文字对话和 NPC 语音后端暂未接入公开版**；公开页面不会请求麦克风权限。
人物嘴部保持静止。所有账单及付款都是游戏模拟，不会收款。刷新页面会开始新一局。

## 请帮忙测试

1. 从「开始游戏」完成一整餐；检查人物移动、字幕、点餐、上菜及结局是否连贯。
2. 奶茶选凍／少甜，再改走甜；同款每局只能一份。确认落单后等待追问，再明确提交。
3. 菠蘿油可外卖；咖喱魚蛋售罄。已上菜或打包的订单不能改动。
4. 加水或送餐具后，侍应应等待你的下一次选择，说完才离开。
5. 手机竖屏、横屏及桌面测试菜单、账单和设置；首次点击后应有配乐，可在设置关闭。

反馈请在 Issues 写明：设备及浏览器、操作步骤、期望结果、实际结果；可附截图。请勿上传密钥或私人录音。

## 本机运行（可选语音服务）

需要 Node.js 24 或以上，无需安装依赖。

```sh
node server.mjs
```

打开 http://127.0.0.1:4173/ 。通过环境变量 PORT 可改端口。
需要语音时，把 `.env.example` 复制为 `.env`，在本机填写自己的百炼密钥及工作空间地址。
`.env` 不提交、不发布。后端仅监听本机，不适合直接作为公网语音服务。
真人录音兼容性仍在排查；本机面板提供输入设备选择、音量条及本地麦克风检测。

## 开发及部署

```sh
npm test
npm run test:voice
npm run build:pages
```

Pages 构建仅复制明确列出的前端文件到 `dist/`，并关闭联网语音入口。
源码中的本机模式保持启用，不影响本机语音测试。所有资源使用相对路径，支持 GitHub 项目子目录。
GitHub 仓库 Settings → Pages 选择 GitHub Actions；推送 main 分支后自动验证并部署。

主要文件：`app.js` 页面交互、`controller.js` 演出、`scene.js` 场景绘制、`teahouse-scene/` 业务规则、`voice.js` 本机录音、`server/bailian.mjs` 语音服务。

## 音乐与素材

内置音乐为项目原创港风器乐，可由 `scripts/gen_local_music.py` 重建，并非《千千阙歌》的复制或改编。
设置保留《千千阙歌》官方在线链接和用户自行选择本机音频的入口；没有打包商业歌曲。
背景与人物使用 AI 生成的美术素材。
